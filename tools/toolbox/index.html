    01 / Linux setup

    Helix Toolbox

    Set up and look after a Linux machine from one menu in the terminal.

    Applications, dotfiles and shell configuration, system tweaks, updates, backups and health checks. Every change is planned, shown with its risk, confirmed, verified and recorded.

    • Version 1.26.4
    • MIT

    Download v1.26.4InstallSource on GitHub Documentation

    Open original

    What it does

    • A catalog of hundreds of applications and tweaks, with profiles and a first-run wizard for developer, gaming, privacy and minimal setups.
    • Knows your machine: what is installed and from where (pacman, apt, dnf, zypper, AUR, Flatpak), its version and any waiting updates.
    • The Install Plan shows every step, its risk and any password prompt, and checks conflicts, repositories, hardware and disk space before anything runs.
    • Runs are verified, fall back from the AUR to Flathub when they need to, and land in a history you can read later.
    • Helix Doctor checks the system and offers repairs, which you confirm one by one.
    • Snapshots with Snapper or Timeshift, and Restic backups that are test-restored and checked against SHA-256 sums.
    • Drift checks, moving a setup between distributions, firmware and hardware health, systemd services, Git repositories and Home Manager generations.
    • A Ctrl-K command palette, a desktop window, and a command line where everything takes --dry-run and --json.

    Requirements

    Runs on
    Linux on x86_64 or aarch64 with glibc 2.35 or later. Tested on Arch, Debian, Ubuntu 22.04 and 24.04, Fedora and openSUSE Tumbleweed.

    Install

    Try it without installing

    curl -fsSL https://raw.githubusercontent.com/Commanderx-code/Helix-toolbox/main/start.sh | sh

    Arch

    Download the package from the latest release, then:

    sudo pacman -U helix-toolbox-*-x86_64.pkg.tar.zst

    Debian and Ubuntu

    sudo apt install ./helix-toolbox_*_amd64.deb

    Fedora

    sudo dnf install ./helix-toolbox-*.x86_64.rpm

    Any distribution, with Cargo

    cargo install --locked helix-toolbox

    1. v1.26.4Helix Toolbox v1.26.4November 9, 2026

      Helix Toolbox v1.26.4, built from commit 00da03d114c24b489cf347bf1a8d63988555876e.

      Linux x86_64 and aarch64 (ARM64), built on Ubuntu 22.04 (glibc 2.35 or newer).

      Install the package for your distribution, or run the program directly:

      # x86_64
sudo pacman -U helix-toolbox-1.26.4-1-x86_64.pkg.tar.zst   # Arch and derivatives
sudo apt install ./helix-toolbox_1.26.4-1_amd64.deb        # Debian, Ubuntu
sudo dnf install ./helix-toolbox-1.26.4-1.x86_64.rpm       # Fedora
sudo zypper install --allow-unsigned-rpm ./helix-toolbox-1.26.4-1.x86_64.rpm   # openSUSE

# aarch64 (ARM64)
sudo pacman -U helix-toolbox-1.26.4-1-aarch64.pkg.tar.zst  # Arch Linux ARM
sudo apt install ./helix-toolbox_1.26.4-1_arm64.deb        # Debian, Ubuntu, Raspberry Pi OS
sudo dnf install ./helix-toolbox-1.26.4-1.aarch64.rpm      # Fedora, Fedora Asahi Remix
sudo zypper install --allow-unsigned-rpm ./helix-toolbox-1.26.4-1.aarch64.rpm   # openSUSE

      The window (docs/GUI.md), which needs the helix-toolbox package above:

      sudo pacman -U helix-toolbox-gui-1.26.4-1-x86_64.pkg.tar.zst   # Arch and derivatives (aarch64 for ARM64)
sudo apt install ./helix-toolbox-gui_1.26.4_amd64.deb      # Debian, Ubuntu (arm64 for ARM64)
sudo dnf install ./helix-toolbox-gui-1.26.4-1.x86_64.rpm   # Fedora, openSUSE (aarch64 for ARM64)
chmod +x helix-toolbox-gui_1.26.4_amd64.AppImage && ./helix-toolbox-gui_1.26.4_amd64.AppImage   # any distribution

      Arch and its derivatives can take both packages from the repository at https://commanderx-code.github.io/Helix-toolbox instead, which pacman then updates with the rest of the system (docs/INSTALL.md).

      Check a download with sha256sum --check --ignore-missing SHA256SUMS, and where it was built with gh attestation verify <file> --repo Commanderx-code/Helix-toolbox. See docs/INSTALL.md.

      The files named helixforge-* are the same files under the name before 1.7, for copies of HelixForge to update from.

      The *-sbom.cdx.json files are CycloneDX software bills of materials: every crate in the program and the window, and the window's frontend packages.
