    04 / TV

    webOS Launcher

    A minimal home screen for LG webOS TVs.

    Favorites, Plex rows, inputs, moving themes and a screensaver, made for a stock TV in Developer Mode (webOS 5 and later). Plain HTML, CSS and JavaScript.

    • MIT

    Install Source on GitHub Documentation

    Open original

    What it does

    • Weather and clock, a Favorites row, and recently used apps on rooted TVs.
    • Plex rows: Continue Watching, Recently Added, and Watchlist on rooted TVs.
    • All Apps you can rearrange and hide. Inputs show only what is plugged in, named after the device.
    • Themes: Ambient, Aurora, Midnight, Ocean, Sunset and Starry space, or your own picture or video wallpaper.
    • Icons as the apps ship them, or glass tiles in white, brand color or ice blue.
    • A screensaver with clock and weather over your photos and videos, or Plex art.
    • Syncs and updates itself every hour.
    • On rooted TVs: a phone remote page, commercial mute, layout backup and app updates.

    Requirements

    Runs on
    An LG TV with webOS 5 or later in Developer Mode, or rooted with Homebrew Channel. Node.js 20 or later on a computer on the same network.

    Install

    Connect the TV

    Turn on Developer Mode and Key Server on the TV first. Use your TV’s address, and the passphrase Developer Mode shows.

    git clone https://github.com/Commanderx-code/webos-launcher
cd webos-launcher
npm install
npx ares-setup-device -a tv -i "host=192.168.1.50" -i "port=9922" -i "username=prisoner"
npx ares-novacom -d tv --getkey
npx ares-setup-device -m tv -i "privatekey=tv_webos" -i "passphrase=XXXXXX"

    Sign in to Plex

    npm run plex-login

    Install it

    The TV asks once to allow the connection; accept it with the remote.

    npm run sync
npm run deploy
