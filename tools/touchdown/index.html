Touchdown

Live NFL scores and stats in your terminal.

A keyboard-driven dashboard for game day: live, final and upcoming games, your team’s season at a glance, and a game center with box scores and play-by-play.

  • Version 0.1.0
  • MIT

Download v0.1.0InstallSource on GitHub Documentation

What it does

  • A scores dashboard with live, final and upcoming games, a card for your team, and standings on wide terminals.
  • Your team’s view: next matchup, latest result, bye week, schedule, record and stat leaders.
  • A game center with box scores, player stats, play-by-play, quarter scores, scoring plays and drives.
  • Follow any team, in one of three themes: mint, amber or mono.
  • Optional desktop alerts when your team scores.
  • Keeps working offline from cached results, marked as cached.
  • td -once prints the scores once and exits, for scripts and status bars.

Requirements

Runs on
Linux, macOS and Windows. Prebuilt binaries come with SHA-256 sums; building needs Go 1.24 or later.

Install

Download

Get the Linux, macOS or Windows archive from the latest release, check it against the SHA-256 file, and put touchdown (touchdown.exe on Windows) somewhere on your PATH.

From a clone

git clone https://github.com/Commanderx-code/touchdown-cli.git
cd touchdown-cli
make install
td

Pick your team

td -set-favorite BUF

    Touchdown v0.1.0

    First public release of Touchdown, a keyboard-driven NFL scores and stats dashboard for the terminal.

    Highlights

    • Live scores, weekly matchups, conference standings, and a favorite-team dashboard.
    • Team schedules, next kickoff, bye weeks, season leaders, and game details.
    • Configurable favorite team and color theme, cached responses, and optional desktop alerts.
    • td shortcut when installed from source with make install.

    Downloads

    Choose the archive for your operating system and CPU: Linux, macOS, or Windows on AMD64 or ARM64. Each archive contains the executable, README, and MIT license. Download SHA256SUMS to verify the archive's checksum.

    The release binaries are unsigned. Builds for all six targets completed successfully; runtime smoke testing was performed on Linux AMD64. macOS, Windows, and ARM64 runtime behavior has not been tested on those systems.

    Touchdown uses publicly accessible, undocumented ESPN endpoints. Live data and stats depend on those endpoints remaining available.
